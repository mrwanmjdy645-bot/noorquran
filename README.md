# نور القرآن

موقع عربي RTL لقراءة القرآن الكريم والاستماع للتلاوات ومتابعة مواقيت الصلاة.

## الملفات
- `index.html`: هيكل الموقع.
- `style.css`: التصميم والألوان والتجاوب.
- `script.js`: جلب السور والآيات والقرّاء ومواقيت الصلاة والأذكار.

## التشغيل على Windows
1. فك ضغط ملف ZIP.
2. افتح المجلد في Visual Studio Code.
3. شغّل `index.html` عبر إضافة Live Server، أو افتحه مباشرة في المتصفح.
4. اسمح للموقع باستخدام الموقع الجغرافي عند ظهور الرسالة لحساب مواقيت الصلاة تلقائياً. يجب استخدام HTTPS أو localhost حتى تعمل صلاحية الموقع في أغلب المتصفحات.
5. يمكنك اختيار مدينة يدوياً من قائمة مواقيت الصلاة إذا لم ترغب في مشاركة الموقع.

## مصادر البيانات عبر الإنترنت
- القرآن الكريم والطبعات الصوتية: AlQuran Cloud API (`api.alquran.cloud`).
- مواقيت الصلاة: AlAdhan API (`api.aladhan.com`).
- تحديد إحداثيات المدن المختارة: OpenStreetMap Nominatim.

يتطلب الموقع اتصالاً بالإنترنت. الخدمات الخارجية قد تتغير أو تتوقف مؤقتاً، وقد تختلف مواقيت الصلاة بحسب طريقة الحساب والجهة المحلية. راجع إعدادات الجهة الرسمية في بلدك قبل الاعتماد النهائي على المواقيت.

## ملاحظات مهمة قبل النشر
- هذه نسخة أولية عملية وليست تطبيقاً معتمداً من جهة دينية.
- راجع نص القرآن والرواية والتشكيل ومصادر الأذكار مع مصدر موثوق قبل إطلاق الموقع للجمهور.
- قائمة القرّاء تعتمد على ما توفره واجهة API وقت التشغيل. قد لا تتوفر كل تلاوة لكل قارئ.
- مشغل الصوت الحالي يبدأ من رابط أول آية في السورة؛ يمكن تطويره لاحقاً لتجميع تلاوة السورة كاملة أو استخدام مصدر موثوق يوفر ملف السورة كاملاً.
- لا تُرسل إحداثيات الموقع إلى خادم خاص بالموقع؛ يتم طلبها من خدمة مواقيت الصلاة لحساب المواقيت.
